## 🤝 Contributing

### 1. Clone the Repository
Clone the project and navigate to the root directory:
```bash
git clone https://github.com/Bogdan-Borunov/Cython-Compiler
cd Cython-Compiler
```

### 2. Run the Program
To launch the compiler, execute the following command:
```bash
python3 compiler.py
```

### ⚠️ Project Cleanup (Optional)
If you need to completely remove documentation and configuration files from your local copy, use the appropriate commands for your OS.

**Windows (Command Prompt):**
```cmd
del .gitignore README.md CHANGELOG.md
rmdir /s /q docs
```

**Linux / macOS:**
```bash
rm -rf .gitignore README.md CHANGELOG.md ./docs
```

> ❗ **Warning:** These commands permanently delete essential project files. We strongly advise **against** executing them if you intend to modify the code or run the compiler under normal conditions.

### 🚀 Submit a Pull Request
Contributions are highly welcome! To contribute to this project:
1. Fork the repository and create a new branch for your changes.
2. Commit your updates and open a Pull Request.
3. If you find this project helpful, please support it by **leaving a star** ⭐ on the repository. Thank you!
